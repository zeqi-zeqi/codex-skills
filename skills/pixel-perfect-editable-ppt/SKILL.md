# 原比例高保真复刻为可编辑 PPT

使用 presentations 技能创建、渲染和验证 PPTX。目标是忠实复刻视觉、比例和坐标关系；“一比一”不表示正方形画布。

## 不可违反的约束

- 总图是页面比例、结构、坐标、尺寸和层级的唯一依据；用户显式指定优先。
- 所有对象使用同一套源图像素到幻灯片坐标的缩放映射，不为适配标准画幅而重排、压缩或拉伸。
- 文字、标题、边框、色块、面板、箭头、连接线和简单图形使用原生 PowerPoint 对象。
- 照片、复杂图标、机械模型、仿真图和工程图可使用独立局部截图；禁止将整张源图作为全页背景。
- 匹配源图的字体观感、字号层级、颜色、线宽、圆角、间距、对齐、换行和对象层级。
- 输出新文件，不覆盖源图片或已有演示文稿。

## 视觉素材模式

- 默认模式：照片、图标和复杂视觉使用独立局部截图。
- 占位模式：当用户说“图标图片不裁切”“图片不裁切”“图标和图片用方块占位”“只还原文字框图”或同义要求时，读取 [references/placeholder-mode.md](references/placeholder-mode.md)，并以该模式覆盖默认截图流程。

## 高效工作流

1. 静默扫描输入，先读取文件名、像素尺寸和必要的缩略图。文件夹输入时读取 [references/folder-input.md](references/folder-input.md)；单图输入不要读取它。
2. 首次视觉分析建立对象清单与统一坐标映射。默认模式查看总图及一张分图联系表；占位模式只查看总图，不打开分图。
3. 先创建页面和主体面板，再添加连接线、节点、文字，以及默认模式的局部截图或占位模式的可编辑占位形状，保持层级正确。
4. 初版完成后集中渲染并运行溢出检查。以并排图或联系表批量比较源图与渲染图；修订时只重新检查受影响的页面和区域。
5. 仅在默认模式的截图出现缺边、错位、邻近内容或清晰度问题时，读取 [references/screenshot-repair.md](references/screenshot-repair.md)。不要预先加载或调用 imagegen。
6. 完整视觉检查通常集中在初版与最终版；仅在检测到未解决差异时增加轮次。密集复杂页面或检查失败时读取 [references/quality-check.md](references/quality-check.md)。

## 上下文与输出控制

- 批量执行文件扫描、渲染和检查；工具在对话中只返回摘要、警告和错误，详细日志写入工作目录。
- 不打印完整文件清单、对象清单、生成脚本或成功日志；需要时按关键词读取局部内容。
- 不重复载入未变化的图片、页面或工具输出。
- 不使用 subagent，除非用户明确要求并行代理工作。
- 交付时仅简要说明原生可编辑区域、截图或占位区域、验证结果及是否使用 imagegen。
