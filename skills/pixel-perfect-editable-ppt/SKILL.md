# 原比例高保真图片复刻为可编辑 PPT

把用户提供的参考图片完整复刻为可编辑 PPTX。这里的“一比一复刻”指视觉、比例和坐标关系忠实于源图，不是把页面设成正方形 1:1。

使用 presentations 技能完成 PowerPoint 创建、渲染和验证。只有在局部截图无法通过重新裁切修复时，才使用 imagegen 技能修复独立视觉素材。

## 忠实度契约

- 保持源图原始长宽比；除非用户明确要求，否则不得改成 16:9、4:3 或其他标准比例。
- 按源图像素坐标建立统一缩放映射，所有对象使用同一坐标系定位。
- 文字、标题、边框、色块、面板、圆角框、箭头、连接线和简单图形必须使用原生 PowerPoint 对象。
- 照片、复杂图标、机械模型、仿真图、工程图和难以可靠重绘的视觉区域可以使用局部截图。
- 每个截图区域必须是独立图片对象；不得将整张源图作为全页背景冒充可编辑版本。
- 不得为了适配标准画幅而重排、压缩或拉伸内部框图。
- 匹配源图的颜色、字体观感、字号层级、线宽、圆角、间距、对齐、换行和对象层级。

## 分解与制作

1. 检查全部输入图片的像素尺寸、色彩模式和清晰度，确定页面比例。
2. 逐区识别标题栏、分栏、面板、流程节点、箭头、分隔线、正文和图片区域。
3. 将源图分成两类对象：
   - 可编辑对象：文字与可由 PowerPoint 原生形状可靠表达的几何元素。
   - 截图对象：照片、图标、复杂工程视觉和其他不适合原生重绘的区域。
4. 对截图保留少量背景余量，避免裁掉描边、阴影、圆角或图标边缘；需要透明背景时，优先从源图可靠提取。
5. 先建立页面与主体面板，再添加连接线和箭头，随后添加节点、文字和截图，保持正确层级。
6. 输出新 PPTX，不覆盖用户的源图片或已有演示文稿。

## 截图错误修复顺序

发现截图缺边、错位、带入邻近文字、分辨率不足或背景不一致时，按以下顺序处理：

1. 回到分辨率最高的源图重新确定裁切框并重新截图。
2. 调整截图的 contain、cover、crop、位置或遮罩，保留正确主体比例。
3. 如果存在同一视觉的更清晰源图，改用该图重新裁切。
4. 只有前三步无法修复时，调用 imagegen，以错误截图或源图局部作为参考进行局部修复或重建。

使用 imagegen 时必须保持原图的构图、颜色、视角、轮廓、背景和图标语义。不得用生成内容改写技术数据、表格数值、工程尺寸、文字标签或其他事实性内容；这些区域只能重新截图或原生重建。

## 质量验证

- 导出并渲染每一页 PPT。
- 将最终渲染与源图并排检查，重点比较外轮廓、列宽、行高、面板位置、边距、对齐、颜色和换行。
- 检查所有文字是否可编辑，所有截图是否为独立图片对象。
- 修复意外重叠、越界、裁切、字体回退、错误换行、模糊截图和错误层级。
- 运行演示文稿溢出检查；未完成逐页视觉检查前不得交付。
- 交付时简要说明哪些区域是原生可编辑对象，哪些区域使用了截图，是否使用图片生成修复过素材。
