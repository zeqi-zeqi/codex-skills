# 文件夹输入

仅在输入包含总图与分图，或用户另行指定分图目录时读取。

若已启用占位模式，只识别总图并跳过分图匹配、缩略图联系表和分图内容检查；以下分图规则仅适用于默认模式。

- 扫描指定范围内的图片，用文件名、像素尺寸和内容完整性识别总图；名称含“总图”“总体”“overall”或“main”的图片优先作为候选。
- 总图决定页面比例、整体版式和所有对象坐标。分图仅作为更清晰的局部素材，不得改变总图结构，也不得默认生成单独页面。
- 用文件名和视觉内容把分图匹配到总图中的照片、图标、工程图或仿真图区域。优先生成一张带文件名的缩略图联系表集中检查，避免逐张载入。
- 找不到匹配分图时，使用总图对应区域继续制作，不中断整个任务。
- 只有多张总图候选无法区分，或错误匹配会明显改变语义时，才向用户简短澄清。
