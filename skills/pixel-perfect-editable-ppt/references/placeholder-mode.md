# 图标与图片占位模式

用户明确要求“图标图片不裁切”“图片不裁切”“图标和图片用方块占位”“只还原文字框图”或同义表达时启用。用户未提出此要求时，不要自动启用。

## 制作规则

- 只用总图判断布局和媒体区域边界；不要打开、匹配或裁切高清分图，也不要生成分图联系表。
- 原生重建标题、正文、独立标签、面板、边框、色块、箭头、连接线和简单几何，保持其坐标、尺寸、样式、换行与层级。
- 每个照片、图标、机械模型、工程图、仿真图或其他复杂视觉区域，用一个独立、可编辑的 PowerPoint 矩形占位。占位矩形保持该区域的位置、宽高、旋转和层级；如果媒体位于原生外框内，只占据实际媒体区域，避免重复外框。
- 占位矩形默认使用浅灰填充、灰色虚线描边。较大的区域居中写“图片占位”，小图标区域可不写文字，避免标签溢出。
- 位于图片内部、属于图片内容的文字随该区域占位；图片外部或覆盖在图片上的独立版式文字仍须原生重建。
- 禁止嵌入或裁切源图片、图标及分图，禁止调用 imagegen，也不要读取截图修复 reference。

## 验证

- 确认文字和框图可编辑，媒体占位形状数量与总图中的独立媒体区域一致。
- 确认占位形状没有遮挡应重建的文字、边框或连接线。
- 交付时说明已启用占位模式，并简要报告图片占位和图标占位数量。

示例请求：`请使用 $pixel-perfect-editable-ppt 复刻 XXX 文件夹中的总图，图标图片不裁切。`
