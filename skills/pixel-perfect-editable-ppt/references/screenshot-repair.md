# 局部截图修复

仅在截图缺边、错位、带入邻近内容、清晰度不足或背景不一致时读取，并依次处理：

1. 回到分辨率最高的源图重新确定裁切框，保留少量背景余量以覆盖描边、阴影、圆角和图标边缘。
2. 调整 contain、cover、crop、位置或遮罩，保持主体原始比例；需要透明背景时优先从源图可靠提取。
3. 如有同一视觉的更清晰分图，改用该图重新裁切。
4. 前三步仍无法修复时，才加载 imagegen 并以错误截图或源图局部为参考修复独立视觉素材。

imagegen 必须保持原图构图、颜色、视角、轮廓、背景和图标语义。禁止生成或改写技术数据、表格数值、工程尺寸、文字标签及其他事实性内容；这些区域只能重新截图或原生重建。
